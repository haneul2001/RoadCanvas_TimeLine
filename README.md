# Road Canvas : TimeLine

달리면 자동으로 채워지는 나만의 여행 지도, 말 한마디로 완성되는 다구간 여행 내비.

차가 실제로 달린 길을 기록해 방문한 시·군·구를 지도에 색칠하고, 지나온 경로를 타임랩스로 다시 보여 주며, 여러 목적지를 말하면 들를 순서를 정해 기본 내비에 이어서 안내하는 Pleos Connect 차량용 여행 앱입니다.

> 개발 중입니다. 아래 기능은 Pleos Connect 에뮬레이터에서 동작을 확인했습니다.

## 주요 기능

| 기능 | 설명 | 상태 |
|---|---|---|
| Auto Canvas | 주행 위치를 시·군·구 경계와 대조해 방문 지역을 자동 색칠 | 동작 |
| Canvas Quest | 아직 안 가 본 지역을 찾아 다음 여행지로 추천 | 동작 |
| Smart Detour | 다음 목적지로 가는 길에 조금만 돌아가면 들를 수 있는 새 지역 추천 | 동작 |
| Route Replay | 지나온 경로를 지도 위에 시간순으로 재생 | 동작 |
| Collection | 스티커 도감(95종)·업적·지역 탐험 미션, 획득 팝업 | 동작 |
| Voice Planner | 여러 목적지를 말하면 순서를 정해 기본 내비에 한 곳씩 안내 요청 | 동작 (음성 인식은 마이크 입력 확인 중) |
| 지도 꾸미기 | 지도 위에 낙서·도형·업적 스티커·직접 만든 스티커 붙이기 | 동작 |
| 여행 기록 · 설정 | 지난 여행 다시 보기·삭제, 기록 제외 구역, 전체 삭제 | 동작 |

주행 중에는 음성만 쓰고, 지도 꾸미기·타임랩스 같은 화면 조작은 기어 P이고 시스템 주행 UX 제한(CarUxRestrictions)이 없을 때만 열립니다.

### 스티커 도감 · 업적 · 여행 통계

- 스티커 그림 95종(자연·관광지·음식·액티비티·계절·업적·지역, 꾸미기용 날씨·감정)을 팀이 만든 스티커 시트에서 잘라 넣었습니다.
- **모으는 스티커 77종**은 실제 기록으로만 받습니다.
  - 추천 여행지 근처(1km)를 지나며 그 지역 방문이 확정되면, 그 여행지 종류(산·바다·사찰·시장…)
  - 시·도 첫 방문 확정: 지역 스티커
  - 방문한 날짜: 계절 스티커(봄·여름·가을·겨울, 크리스마스 등)
  - 업적: 첫 방문, 재방문, 계획 완주, 시·군·구 10곳, 시·도 5곳, 전국, 사흘 연속, 누적 1,000km, 첫 꾸미기, 레벨 3
- 새 스티커를 받으면 정차 중에 "새로운 스티커를 획득했어요!" 팝업이 뜹니다. **스티커 도감**에서 분류별로 보고, 못 받은 스티커는 눌러서 얻는 방법을 봅니다.
- **여행 통계**(메인 위쪽 버튼): 전국 시·군·구 방문률, 총 이동 거리, 여행 횟수, 방문 지역, 모은 스티커, 누적 거리로 오르는 **여행 레벨**.

### 시·군·구 추천 여행지 · 추천 코스

- 전국 256개 시·군·구마다 대표 여행지 3곳(종류·한 줄 소개·좌표)과 들르는 순서(추천 코스)를 넣었습니다(`app/src/main/assets/spots.json`).
- 메인 지도에서 시·군·구를 누르면 지역 카드가 떠서 방문 상태, 추천 여행지, 추천 코스를 보여 줍니다. **여기로**를 누르면 바로 내비 안내, **이 코스로 여행 계획 만들기**를 누르면 세 곳이 순서대로 계획에 들어갑니다.
- "속초 뭐가 유명해?"라고 물으면 그 지역 추천 여행지로 답합니다.
- 여행지 정보는 공개된 관광 정보를 바탕으로 정리한 것이고, 좌표는 근사값입니다. 모든 좌표가 해당 시·군·구 경계 안(바닷가는 해안선에서 3km 이내)에 있는지 스크립트로 검사했습니다.

### 메인 화면

- 앱을 켜면 **현재 위치**를 가운데 둔 지도가 나옵니다. 왼쪽에는 지금 있는 시·도 / 시·군·구 / 읍·면·동, 기록 상태(기록 중·주차 중), 지금 시·도의 색칠 진행률, 여행 시작·마치기 버튼이 있습니다.
- **등록된 경로**(Voice Planner나 추천으로 정한 들를 곳)가 있으면 지도에 현재 위치부터 주황 점선과 번호 핀으로 그리고, 오른쪽 경로 카드에 다음 목적지와 남은 곳, 출발 버튼을 보여 줍니다. 없으면 '말로 계획하기', '안 가 본 곳 추천'으로 안내합니다.
- 정차 중에는 지도 오른쪽 **＋ / − / ⟲** 버튼으로 확대·축소·원래대로 할 수 있습니다(손가락으로 끌기·벌리기도 됨).
- 지도 위 스티커는 **지도 꾸미기로 직접 붙인 것만** 보입니다. 받은 스티커는 스티커 도감에 쌓이고, 추천 여행지는 지도에서 시·군·구를 누르면 뜨는 지역 카드와 Canvas Quest에서 봅니다.
- 지도 위 **년 ▾ · 월 ▾** 토글로 기간을 고르고 **📜 여행 히스토리**를 누르면 그 달의 여행 목록(날짜·거리·새 지역)이 뜹니다(✕로 닫기). 여기서 **월별 타임랩스**, **연도별 타임랩스**, 여행 하나 다시 보기를 메인 지도에서 바로 재생합니다(여러 여행은 사이 빈 시간을 건너뛰고 이어서, 막대에 실제 날짜 표시).
- 앱이 한 말은 음성 말풍선에 12초 동안 보였다가 다시 '목적지를 말해 보세요'로 돌아갑니다.
- 아래 런처의 **TimeLine**에서 여행 통계·타임라인·타임랩스 화면으로 갑니다. 주행하다 주차(P)하면 이 화면으로 넘어가 이번 여행 타임랩스를 자동 재생합니다.

### Auto Canvas 동작 방식

- 사용자가 **여행 시작**을 누르고 위치 권한을 허용해야 기록합니다. 기록은 기기 안에만 저장합니다.
- Pleos FusedLocation으로 받은 좌표를 시·군·구 경계와 대조해 처음 지나간 곳은 **통과**, 한곳에 머문 곳은 **방문 확정**으로 진하게 칠합니다. 통과만으로는 방문을 확정하지 않습니다.
- 색칠 기준을 **시·도 / 시·군·구 / 읍·면·동** 세 단계로 바꿔 볼 수 있습니다. 판정은 늘 세 단계를 함께 하고, 진행률은 단계에 맞춰(전국 시·도 중 / 지금 시·도 안 / 지금 시·군·구 안) 보여 줍니다.
- 지도는 방문한 순서대로 무지개색으로 칠하고(머문 곳은 진하게), 이번 여행 범위로 자동 확대합니다. 경로선은 차가 실제로 지나간 위치 기록을 그대로 잇습니다.
- 정차 중에는 지도를 끌어서 옮기고 두 손가락으로 확대할 수 있으며, 두 번 탭하면 여행 범위로 돌아옵니다. 주행 중에는 지도 조작이 잠깁니다.
- 여행 타임라인에 출발 · 첫 방문 · 머문 곳 · 여행 종료 요약이 시간순으로 쌓입니다.
- 처음 들어온 시·도와 처음 지나는 시·군·구마다 한 번, 짧은 음성으로 알려 줍니다(읍·면·동은 너무 잦아 화면에만 기록).
- 내비가 화면 앞에 있어도 기록이 이어지도록 포그라운드 서비스로 동작합니다.

### Route Replay 동작 방식

- **타임랩스 보기**를 누르거나, 주행하다 기어를 **P(주차)** 로 바꾸면 이번 여행을 약 14초 동안 다시 보여 줍니다.
- 경로선이 시간순으로 그려지고, 처음 지난 지역이 그 순간에 칠해지며, 거리·새 방문 지역·진행률·타임라인도 그 시점 값으로 함께 움직입니다.
- 이번 여행 전에 다녀온 지역은 처음부터 칠해진 채로 시작합니다.

### 방문 확정과 Collection

- 한곳(반경 300m)에 5분 넘게 머물면 묻지 않고 그 시·군·구를 **방문 확정**합니다. 고속도로로 지나가기만 한 곳은 '통과'로만 남습니다.
- 방문이 확정되면 그 지역(과 머문 읍·면·동, 상위 시·도)이 확정되고 **지역 스티커**를 받습니다. 여행 경로가 근처(1km)를 지난 대표 명소가 그 지역에 있으면 **장소 스티커**도 함께 받습니다.
- **Collection** 화면에서 받은 스티커와 지역 탐험 미션(강원 18개 시·군, **동해안 7번 국도 완주**(부산 기장~강원 고성 12개 시·군), 동해안 여행지 탐험, 전국 시·도, 전국 시·군·구) 진행률(%)을 봅니다.

### 지도 꾸미기

- 정차 중 홈 지도 왼쪽 위 **🎨 지도 꾸미기**를 누르면, 지금까지 다닌 모든 여행이 담긴 지도에서 꾸밀 수 있습니다.
- 도구: **펜**(낙서), **지우개**(문지른 낙서·도형·스티커 삭제), **도형**(네모·동그라미·화살표), **스티커**, **이동**(끌기·확대). 색 8가지, 굵기 3단계, 되돌리기, 모두 지우기.
- 스티커는 방문 확정으로 받은 **업적 스티커**(장소 ⭐·지역 🏅)와, 이모지·짧은 글·색으로 직접 만드는 **내 스티커**를 붙일 수 있습니다.
- 꾸민 것은 지도 좌표(위·경도)에 붙어 있어 지도를 옮기거나 확대해도 그 자리에 있고, 홈 지도에도 함께 보입니다. 기기 안(decorations.json, custom_stickers.json)에만 저장됩니다.

### Voice Planner 동작 방식

- 홈 화면의 음성 말풍선이나 **Voice Planner** 화면의 마이크를 누르고 "속초, 양양, 강릉 들렀다가 서울로"처럼 말합니다. Pleos 음성 인식(STT)으로 받은 문장을 앱 안의 규칙(지역명 사전 + 문장 틀)으로 해석합니다.
- 들를 순서는 앱이 계산합니다(지금 위치에서 총 이동 거리가 가장 짧은 순서, "○○로"로 끝난 곳은 마지막). 계산한 순서를 음성으로 알려 주고 **출발**하면 첫 목적지를 기본 내비에 요청합니다. 내비가 돌려준 예상 시간을 그대로 읽어 줍니다.
- 기본 내비 SDK가 받는 경유지는 최대 2곳이라, 목적지를 한 곳씩 차례로 요청합니다. 목적지 1km 안에 들어오거나 내비가 도착을 알리면 "○○에 도착했어요. 출발하실 때 출발이라고 말씀해 주세요"라고 안내하고, 출발하면 다음 곳을 요청합니다.
- "양양 말고 주문진 먼저", "강릉은 빼줘"처럼 말하면 계획을 고칩니다. 안내를 시작하면 여행 기록도 함께 켭니다.
- "속초 뭐가 유명해?"처럼 물으면 앱에 넣어 둔 대표 명소(한 줄 소개 포함)로 짧게 알려 줍니다(외부 관광 정보 없이).
- 마이크가 없는 환경에서도 시험할 수 있게 예시 문장을 눌러 같은 흐름을 보낼 수 있습니다.

### Canvas Quest · Smart Detour

- **계획에 추가 / 코스로 계획 / 바로 안내**를 누르면 바로 기본 내비에 안내를 맡깁니다. 이미 안내 중이면 '계획에 추가'한 곳은 지금 목적지 앞 경유지로 내비에 들어갑니다(내비 경유지는 최대 2곳).
- **Canvas Quest**: 아직 칠하지 않은 시·군·구를 지금 위치에서 가까운 순으로 보여 줍니다(시·도별로 거르기, 대표 명소가 있는 곳을 조금 앞에). **바로 안내**는 내비에 바로 요청하고, **계획에 추가**는 Voice Planner 순서에 넣습니다.
- **Smart Detour**: Voice Planner의 다음 목적지로 가는 길에 15/30/60분 안쪽만 더 들르면 칠할 수 있는 곳을 고릅니다. 추가 시간은 직선 거리를 평균 시속 60km로 나눠 어림한 값이라 화면에 "추정"으로 표시하고, 실제 도로 거리·시간은 경유지를 넣은 뒤 내비가 알려 줍니다.
- 관광 정보는 외부 API 없이 앱에 넣어 둔 대표 명소만 씁니다.

### 여행 기록 · 개인정보

- **기록 보기**에서 여행별·**주간·월별·연도별**로 묶어 지도와 타임랩스로 다시 봅니다. 기간을 고르면 그 안의 여행을 이어서 재생합니다(여행 사이 빈 시간은 건너뜀). 여행별 보기에서는 여행 하나를 지울 수 있습니다(그 여행에서만 간 곳과 받은 스티커도 함께 지워짐).
- 지역마다 **다녀온 횟수**(그 지역을 지난 여행 수)를 세어 **많이 간 곳** 순위로 보여 줍니다.
- **자동 기록**(설정, 기본 꺼짐): 설명을 보고 동의해 켜면 기어를 D로 바꿀 때 여행이 자동으로 시작되고, 주차(P)한 채 30분이 지나면 자동으로 끝납니다. 직접 '여행 시작'한 여행은 자동으로 끝내지 않습니다. 대기 중에는 위치를 저장하지 않고 알림만 떠 있습니다.
- 저장량을 줄이려고 50m 이상 움직였거나 10초가 지난 점만 저장합니다(머문 곳 판정은 그대로).
- 앱이 화면에 보이는 동안에는 기록하지 않아도 메인 화면에 현재 위치를 표시합니다(저장하지 않음).
- **기록 제외 구역**: 집·회사처럼 남기기 싫은 곳을 반경 500m로 등록하면 그 안의 위치는 저장도 색칠도 하지 않습니다.
- 여행을 마치면 저장된 값만으로 요약을 들려줍니다. 예: "이번 여행은 587킬로미터를 달렸어요. 새로 방문한 시·군·구 6곳, 스티커 4개를 모았어요. 강원특별자치도는 이제 18곳 중 11곳을 칠했어요."
- 기록 보기에 **전체** 탭이 있어 지금까지 모든 여행을 한 지도와 타임랩스로 봅니다.
- 설정에서 **화면 모드**(밝게·어둡게·시스템 따라)를 고를 수 있습니다.
- 설정에서 **지도 색**(무지개·바다·숲·노을·단색)을 고를 수 있고, 고른 색은 기기에 저장됩니다.

### 테스트 주행

에뮬레이터의 내비 화면 속 차는 GPS 주입으로 움직이지 않기 때문에, 앱 안에서 가상의 차를 달리게 하는 테스트 기능을 넣었습니다. 홈 오른쪽 위 **테스트 주행**에서:

1. 목적지를 고릅니다("속초로", "홍천, 인제 들렀다가 속초로" 등). Voice Planner와 같은 흐름으로 순서를 정합니다.
2. 출발 위치(서울시청 / 마지막 기록 위치)와 시간 배속(×1 ~ ×120, 시속 80km 기준)을 고릅니다.
3. **출발**을 누르면 기본 내비에 경로를 요청하고, 가상의 차가 목적지로 달립니다. 지도 색칠·타임라인·첫 방문 음성·도착 안내가 실제 주행과 같은 코드로 일어나며, 목적지에서는 '출발'을 누를 때까지 서 있습니다(오래 서 있으면 머문 곳으로 기록).
4. 마지막 목적지에 도착하면 여행이 끝나고 요약을 들려줍니다. 테스트 한 번이 여행 하나로 쌓여 기록 보기·타임랩스·많이 간 곳에 반영됩니다.

- 서울·춘천·홍천·인제·속초·양양·강릉·대전·전주·광주·여수·대구·경주·부산 14개 도시 사이(91개 경로)는 앱에 넣어 둔 실제 도로 좌표를 따라가고, 그 밖은 직선으로 갑니다. 도로 좌표는 `scripts/fetch_city_roads.py`로 개발 PC에서 미리 받아 둔 것이라, 앱은 실행 중에 외부 서버를 부르지 않습니다(차 위치가 밖으로 나가지 않음).
- 위치 시각도 배속해서 넣으므로 머문 곳 판정(5분)과 비정상 위치 걸러내기는 실제 주행 기준을 그대로 씁니다.
- **전체 초기화**로 모든 여행·방문·스티커·계획을 지우고 처음 상태로 돌릴 수 있습니다.
- **올해 매주 여행 채우기**(시험용): 올해 1월 첫 토요일부터 오늘까지 매주 여행 하나씩(도시 사이 실제 도로, 2~3곳)을 만들어 월별·연도별 타임랩스와 히스토리를 시험합니다.
- **시연용 샘플 여행**: 지난 6주 동안 춘천·전주·여수·경주·부산·속초·강릉을 다녀온 것처럼 여행 6개를 한 번에 만듭니다(실제 기록과 같은 판정·저장 경로, 음성은 끔). 누적 지도·기간별 타임랩스·스티커·미션을 바로 보여 줄 수 있습니다.

## 테스트 환경

- Pleos Connect Emulator 2.x (Android 14 / API 34, x86_64)
- Android Studio, JDK 17 이상 (Gradle 실행용 JVM은 17~22)
- 일반 휴대폰 에뮬레이터에는 Pleos 차량 서비스가 없어 동작하지 않습니다.

## 실행 방법

1. Android Studio → Settings → Android SDK → SDK Update Sites에 아래 주소를 추가하고, SDK Platforms에서 **Pleos Connect v2.1.0 APIs (API 34)** 이미지를 설치합니다.
   ```
   https://nexus-playground.pleos.ai/repository/raw-releases/connect-avd/2.x/crp-sys-img.xml
   ```
2. Device Manager에서 Automotive → Pleos Connect v2.1.0 기기를 만들고 실행합니다.
   마이크 입력이 필요하면 `scripts/start_emulator.sh`로 실행합니다(`-allow-host-audio` 포함).
3. 빌드·설치(별도 API 키는 필요 없습니다. 쓰는 Pleos SDK는 모두 차량 안 서비스입니다)
   ```bash
   ./gradlew installDebug
   ```
   release 빌드를 직접 만들 때는 서명 키 정보를 `local.properties`에 넣습니다(저장소에는 올리지 않습니다). 없으면 서명 없이 만들어집니다.
   ```
   release.storeFile=C:/경로/키.jks
   release.storePassword=...
   release.keyAlias=...
   release.keyPassword=...
   ```

에뮬레이터 차량 상태(기어 등)는 Virtual Console로 바꿀 수 있습니다: `adb forward tcp:8088 tcp:8088` 후 브라우저에서 `http://127.0.0.1:8088/`.

## 시연: 동해안 주행 재현

앱에서 **여행 시작**을 누른 뒤, 실제 도로 모양의 GPS 경로를 주입합니다(서울 → 홍천 → 인제 → 속초 해변(머묾) → 양양 → 강릉, 약 266km를 3분 안팎으로 압축). 속초 해변에서 머무는 동안 자동으로 방문이 확정되어 속초시·속초 해변 스티커를 받습니다.

```bash
python scripts/demo_trip.py
```

경로 파일 `scripts/routes/east_coast.json`은 `scripts/fetch_route.py`로 한 번 받아 저장해 둔 것이라 시연 때 인터넷이 필요 없습니다.

디버그 빌드는 시간을 압축한 시연을 위해 체류 판정 시간(30초)과 위치 점프 허용 범위를 넓혀 두었습니다. 릴리스 빌드는 실제 주행 기준(체류 5분, 시속 약 250km 이상 점프 무시)을 씁니다.
